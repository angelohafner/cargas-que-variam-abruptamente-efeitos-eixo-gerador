Os dois casos com gerador agora fazem parte do estudo intermitente de **250–500 MW**, com base de máquina/eixo de 1.000 MVA e BESS opcional de 250 MW/125 MWh.

Consulte [o guia atualizado](README_250_500MW.md) e [os resultados medidos](validation/scale_250_500/RESULTADOS.md). O modo entregue é `Mode=0`, com o mesmo perfil de carga dos casos com fonte ideal.

O guia da escala anterior foi preservado no [histórico](history/before_250_500MW_20261026_182420/README_GERADOR_TORCIONAL.md). Não aplique seus valores de potência aos arquivos atuais.
